# 장시간 플레이 자동 검증 검토

상태: 설계 제안. 아래 장시간 수집기·반복 재생 기능은 아직 구현하지 않았으며,
수 시간 연속 플레이를 통과했다는 의미가 아니다.

## 권장 구성

1. 재현 가능한 파일 반복 테스트: 게임 영상을 같은 프로세스에서 반복 입력한다.
   30분 예비 검사 → 2시간 기본 검사 → 8시간 장기 검사로 확대한다.
   매 반복마다 앱/NR을 재실행하면 누적 문제를 놓치므로 세션은 유지한다.
   영상 반복 경계와 의도적인 history reset은 이벤트로 기록한다.
   실제 캡쳐 드라이버·HDMI·오디오·화면 출력 검증을 대신하지 않는다.
2. 실제 플레이 관찰 테스트: 사용자가 플레이하는 기존 앱에 수집기를 붙인다.
   같은 캡쳐카드를 여는 두 번째 앱은 실행하지 않는다. 입력이나 메뉴는 조작하지 않는다.
   무신호 화면도 프레임 수신은 정상일 수 있으므로 입력 움직임/정적 구간을 별도로
   표시하고, 정지 영상·무신호만으로 게임 화질 검증을 통과시키지 않는다.

## 수집과 판정

| 항목 | 권장 수집/판정 | 주의점 |
|---|---|---|
| 프레임 진행 | 1초 간격 capture/present/NR 카운터 차이, 최종 프레임 나이 | 화면 내용이 정적인 것과 프레임 수신 중단을 구분 |
| 성능 저하 | 선택 FPS 대비 지속적 부족, NR 시간 분포, fallback 비율·지속 시간 | 시작/모드 변경/사용자 NR OFF 구간은 별도 분류 |
| 복구/중단 | 앱·워커 종료, heartbeat, 재시작 횟수, device-removed/Present 오류 | 자동 복구되었다고 오류 이력을 지우거나 통과시키지 않음 |
| 메모리 | 앱과 워커의 private bytes·working set 및 가능한 GPU 메모리 지표 | 초기 캐시 증가와 지속 증가를 구분; 미지원 지표는 N/A |
| 암전 | source/output 어두움과 NR 상태·프레임 순서 동시 기록 | 현재 9점 표본은 휴리스틱이며 정상 게임 암전도 검출 가능 |
| 잔상·깜빡임 | 순서가 맞는 원본/NR의 움직임 보정 후 변화량으로 의심 시점 추출 | 완전 자동 화질 합격 판정이 아니라 검토 후보 생성 |
| 오디오 | 출력 큐·오류 기록; A/V 동기화는 별도 기준 영상/음원으로 확인 | 현재 비디오 테스트만으로 장시간 A/V 동기화를 보장하지 않음 |

예비 기준은 워밍업 이후의 연속 이상 구간으로 설정하고, 기기별 정상 측정값에 맞춰
조정한다. 메모리 순간 최고값이나 단일 느린 프레임만으로 실패 판정하지 않는다.
정상적인 처리에서도 초기화 비용이 들며, 사용자가 NR을 끈 구간은 NR 정지 오류가 아니다.
정확한 임계값은 수집기 구현 후 정상/의도적 오류 표본으로 보정해야 한다.

## 구현에 필요한 보완

- 기존 frame rate meter, 워커 heartbeat/처리 시간, 완료 sequence, 복구 횟수,
  GPU/CPU 캡쳐 카운터와 암전 probe를 재사용할 수 있다.
- 현재 제목 문자열과 회전형 이벤트 로그만으로는 시계열 통계가 부족하다.
  버전이 있는 구조화된 1초 JSONL/CSV 진단 출력을 추가하는 것이 우선이다.
- 수집기는 종료 코드와 모드·GPU·드라이버·실행 파일 해시를 포함한 요약 보고서를
  만들고, 원시 기록은 용량 상한과 회전을 적용한다. 영상/오디오 저장은 기본 OFF로 한다.
- 실제 영상 비교가 필요하면 원본과 NR 출력 sequence를 맞춘 제한된 표본 저장을
  별도 선택 기능으로 제공한다. 서로 다른 시점의 영상을 비교하면 거짓 경고가 발생한다.
- 캡쳐 모드는 장치 이름/ID까지 지정하고 실제 선택 결과를 확인해야 한다.
  저장된 해상도만 넣었을 때 다른 기본 모드로 열린 세션을 통과시키면 안 된다.
- 수집기가 소유한 테스트 프로세스만 종료한다. 실제 플레이 관찰은 사용자의 앱을
  종료하지 않는다. 장치 분리·절전·드라이버 재설정은 일반 자동 검사와 분리한다.

## 현재 자동화와의 차이

`tests/live_nr_smoke.ps1`은 격리 설정을 사용하는 짧은 하드웨어 연동 검사다.
장치/포맷/해상도/FPS, GPU 경로 또는 CPU 대체 경로와 NR 출력·정상 종료를 검사한다.
실행 시간은 최대 600초까지 지정할 수 있지만, 최종 상태 위주로 검사하므로
시간만 늘려도 메모리 누수·중간의 일시적 깜빡임까지 검증되는 것은 아니다.
창이 숨겨져 있어 실제 모니터 FPS/화질 판정에도 사용할 수 없다.

`tools/benchmark.ps1`과 화질/성능 비교 도구는 파일 기반 기준 비교에 재사용할 수 있다.
현재는 EOF에서 끝나는 순차 처리이므로 장시간 동일 프로세스 반복 입력은 추가 구현이
필요하다. 우선순위는 구조화 진단 수집 → 실제 플레이 관찰 → 파일 반복 및 화질 후보
추출 순서를 권장한다. 이번 검토에서 장시간 예약 실행이나 자동 감시는 생성하지 않았다.
