# DLSS NR Capture v0.1.0-beta.1

First public Windows x64 beta. This is an experimental capture viewer, not an
official NVIDIA product. NR performance and visual quality depend on the GPU,
runtime, input resolution, frame rate, and scene.

## Included

- Capture device, format, resolution, frame rate, and audio selection with saved settings.
- Full screen (F11), always on top, vertical flip, and DPI-aware window sizing.
- NR toggle (F10), preparation/status notifications, slow-processing fallback,
  live performance overlay, and diagnostic reports.
- GPU input and correction processing, transition/history stabilization, device
  reconnection, bounded audio buffering, and adjustable audio delay.
- Local error/recovery logs and automated regression coverage.

## Install

1. Download the versioned **windows-x64.zip** asset, not the source-code archive.
2. Verify its SHA-256 against the accompanying .sha256 file, then extract to a new folder.
3. Install the Microsoft Visual C++ x64 runtime if it is not already installed.
4. Run dlss-nr-capture.exe; the worker starts automatically.
5. For NR, supply your own compatible, legally obtained nvngx_dlssnr.dll in
   nr-runtime beside the included public bridge. It is NOT included in this release.

The package excludes proprietary NVIDIA runtime binaries, game test videos,
personal settings, and logs. Third-party notices and the public bridge license
are included.

## Known limitations

- Actual NR requires compatible NVIDIA hardware/runtime; hosted CI does not
  establish real-GPU performance or visual quality.
- Capture-card/driver reconnect behavior and long-session audio synchronization
  still need device-specific testing. Audio delay is manual, not automatic sync.
- Some temporal NR runtime sessions can stall during shutdown. Benchmark tooling
  uses bounded cleanup after a completed report; the underlying runtime issue remains.
- The experimental GPU-fence input path is disabled by default.
- This beta has not been validated on a clean Windows installation.
