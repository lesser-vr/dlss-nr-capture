# DLSS NR Capture v0.1.0-beta.2

Experimental Windows x64 prerelease. Not an official NVIDIA product.

## Changes since beta.1

- Native GPU capture and recoverable GPU optical-flow handoff, shared-copy synchronization fixes.
- Capture color handling, device recovery, bounded audio synchronization and capture sleep prevention.
- Same-frame original/NR comparison (F9), held comparison (F8), zoom and side swapping.
- Hold Tab for original video in either normal or comparison view; NR OFF shows guidance without enabling NR.
- Full-height comparison divider and larger centered comparison labels.
- Fullscreen top-edge auto-hiding menus; open menus remain available until dismissed.
- Experimental creative controls and 1/2/3-pass NR; 1 pass remains the default. Settings persist.
- Worker GPU-memory pressure diagnostics, original-video fallback, replay benchmarks and comparison tools.

## Install / upgrade

Download the windows-x64.zip asset and verify its accompanying SHA-256 checksum.
Extract into a new folder. Microsoft Visual C++ x64 runtime is required.
Run dlss-nr-capture.exe; its worker starts automatically.
Supply your own compatible nvngx_dlssnr.dll in nr-runtime. Proprietary NVIDIA
runtime files, original game videos and personal logs/settings are not included.
Keep app, worker and bridge together: this build uses worker protocol 11 and adapter ABI 7.

## Validation and limitations

Local full regression passed 11/11. Three-pass settings save/restore and CLI
bounds were verified. Actual RTX 5090 / 1440p / 100% three-pass replay measured
14.12 ms mean over 300 frames after 120 warmup, zero processing failures and
one frame over 16.67 ms. An 8-second capture smoke ended with correction active
and zero capture drops. These do not establish sustained 60 fresh NR frames/s.
Multi-pass processing can increase artifacts and VRAM use; subjective quality,
long-session play and physical A/V synchronization are not certified.
Fullscreen hover behavior has build/regression coverage but no manual hover acceptance yet.
Video-file playback, VR integration and HUD protection were discussed only and are not included.
